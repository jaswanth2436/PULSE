# PULSE Data Directory

## Structure

```
data/
├── videos/         # Traffic video files (not committed to git)
│   └── README.md   # Instructions for obtaining test videos
├── scenarios/      # Pre-defined simulation scenarios (auto-generated)
└── README.md       # This file
```

## Video Sources

PULSE supports user-provided traffic video. We do not distribute copyrighted footage.

**Recommended sources for testing:**
- Record your own intersection footage
- Use Creative Commons licensed traffic footage from Pexels or Pixabay
- Use synthetic video generated by the PULSE simulation renderer

**Supported formats:** MP4, AVI, MOV (OpenCV compatible)
**Recommended resolution:** 720p or 1080p
**Recommended duration:** 1–5 minutes for testing

## Simulation Data

Simulation scenarios are generated programmatically. See:
`backend/app/simulation/scenarios.py`

Scenarios are reproducible using fixed random seeds:
- Scenario A (Balanced): seed=42
- Scenario B (Eastbound): seed=123
- Scenario C (NS Surge): seed=456
- Scenario D (Traffic Surge): seed=789
